# Numera: Reporting Reimagined

> Draft README. Final version is written in milestone M12. Do not add claims (features, test counts, performance numbers) until they are verified.

Numera is an independent portfolio project: upload a sales CSV, get clear KPIs and charts, drill down to the underlying rows, and export what you find. It uses fictional data from an invented coffee roaster, "Harbor & Pine Coffee".

Built by Bojan Petkovski as a solo project with AI assistance (Claude).
