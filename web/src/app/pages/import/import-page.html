Expected format

The first row must contain these column names (any order, any letter case): order_id, order_date, customer_id, region, channel, product_sku, product_category, quantity, unit_price, discount, status.

  • order_date: yyyy-MM-dd, not in the future
  • quantity: a whole number greater than 0
  • unit_price: at least 0, up to 2 decimals; discount: 0 to 1
  • status: completed, refunded or cancelled
  • An order_id and product_sku pair may appear only once, and is skipped if it was already imported.
  • Unknown columns are ignored with a warning.
  • Both limits apply: rows longer than about 100 characters on average reach 10 MB before 100,000 rows. Split very large files into several imports.
